# MirageCodes
**Система промокодов для Paper 1.21.4+** — игрок вводит `/code &lt;промокод>` и получает награду. Награды выдаются **командами** и **предметами**, плюс сообщения, титры, звуки и объявления. Лимиты, сроки, права, шансы, защита от перебора, генератор одноразовых кодов, лог и уведомления в Discord.
